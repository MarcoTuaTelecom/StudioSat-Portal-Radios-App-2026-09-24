# Android / APK

O material histórico auditado mostra que existiu `RadioStudioSat-v1.1.0.apk`, mas o repositório de origem analisado não contém o código-fonte Android correspondente.

Por isso esta reconstrução **não fabrica um APK novo nem finge recuperar o código nativo antigo**.

O aplicativo entregue neste projeto é o PWA em `player/`, instalável em navegadores compatíveis. Quando o APK histórico ou seu código-fonte forem recuperados do backup do NS1, eles podem ser auditados e adicionados aqui em uma etapa separada.
